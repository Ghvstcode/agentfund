# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The summary below is ours; the linked text is the standard we enforce.

## In short

- Be respectful. Disagree about code, designs and trade-offs, not about people.
- Assume good faith, and make it easy for others to assume yours.
- No harassment, no personal attacks, no publishing anyone's private information.
- This applies in the repository, in issues and pull requests, and anywhere someone is
  representing the project.

One thing specific to AgentFund: pull requests here may be written by a coding agent on a
backer's behalf. Review the diff as hard as you like. The person who donated the run did not
write it and is not the target.

## Reporting

Report a problem privately to the maintainers through the repository's
**Security → Report a vulnerability** form, marked "conduct", or to the contact listed on the
repository's organisation page. A dedicated contact address has not been set up yet; this
section will name one before launch.

Reports are kept confidential. Maintainers may remove comments, lock threads, or ban
contributors whose behaviour breaks these rules, and will say why.
